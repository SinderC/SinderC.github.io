SinderC

Browser tools for engineering data. Each one is a single page that runs locally; your files are not uploaded.

BOM Visualizer

A lightweight, interactive sandbox for bills of materials: edit the structure, set option families, and see which occurrences a configuration includes by variant expression and effectivity.

Drawing Viewer

An offline viewer for DWG, DXF, DWF/DWFx, HP-GL, TIFF and CALS drawings, with zoom, pan, layers and multi-page files. No network access.
